## 非阻断型优化建议

- 外部 `config/levels.json` 能打开但 JSON 损坏时，加载器不会回退到 qrc 内置配置；当前文件有效，因此不阻断本次提交，但答辩前不要直接破坏正式配置。
- 编辑器测试关卡 HUD 显示“关卡 0”（测试关卡索引为 -1 后加 1）；不影响测试逻辑，但展示时略显粗糙。
- Slow/Burn/Stun 同时存在时状态图标按 `Stun > Burn > Slow` 只显示一个；Slow 光环仍可并存。单项清晰度已改善，多状态同时展示仍有限。
- 选中的塔死亡后，选择框可能短暂残留到下一次选择或清场；属于既有小型 UX 风险。
- `QSettings::sync()` 的错误状态未检查；普通用户环境已通过隔离写入测试，受限配置环境仍可能静默失败。
- `Enemy::tickEffects(double, bool onIce)` 的 `onIce` 参数当前未使用，独立测试编译产生一条 `-Wunused-parameter` 警告；冰面倍率实际在 `movementMultiplier` 中实现，不影响功能。
- `用QtCreator打开.bat` 仍硬编码 `D:/Qt/Tools/QtCreator/bin/qtcreator.exe`；这是开发辅助脚本而非运行时资源，换电脑时应直接从 Qt Creator 打开根目录 `CMakeLists.txt`。
- `bin/editor_level.json` 是编辑器测试产生的额外文件，不影响运行，但最终提交前可由本人决定是否作为示例关卡保留并在 README 中说明。
- 菜单和结果页期间主 16 ms 计时器仍持续唤醒；无重复计时器或泄漏证据，但可造成少量空闲 CPU 唤醒。
